# 1. 프로젝트 개요

## BTS란?

> **B**uild **T**eam **S**ervice
> AI 전문가들로 구성된 가상 팀과 함께 기획서를 작성하는 협업 플랫폼

### 해결하고자 하는 문제

| 기존 방식 | BTS 솔루션 |
|-----------|------------|
| 혼자서 기획 → 편향된 시각 | 다양한 전문가 관점 제공 |
| 팀 미팅 일정 조율 어려움 | 24/7 즉시 협업 가능 |
| 초기 아이디어 검증 비용 높음 | 빠른 피드백 루프 |
| 문서화에 시간 소요 | 자동 기획서 생성 |

## 2.2 레벨 시스템

### 주니어 vs 시니어

```
┌──────────────────┬──────────────────┐
│     🌱 주니어     │     🌳 시니어     │
├──────────────────┼──────────────────┤
│ 창의적 아이디어   │ 경험 기반 검증   │
│ 최신 트렌드      │ 리스크 분석      │
│ "해보면 어떨까요?" │ "고려해야 합니다" │
│ 가능성 중심      │ 실현 가능성 중심  │
└──────────────────┴──────────────────┘
```

### 조합의 힘
- 주니어 기획자 + 시니어 개발자 → 혁신적 아이디어 + 현실적 검증
- 주니어 디자이너 + 시니어 QA → 새로운 UX + 품질 보증

# 5. 주요 구현 내용

## 5.5 BCL (BTS Compressed Language)

### AI 간 통신 최적화

**문제:** 긴 대화 히스토리 → 토큰 비용 증가

**해결:** 압축 언어 개발

```
Before (일반):
[민준(기획자)]: 사용자 온보딩 과정에서 게이미피케이션을
도입하면 참여율을 높일 수 있을 것 같습니다.

After (BCL):
민:PLN-J>IDEA{gamification,onboarding}[사용자_온보딩_과정에서]
```

**결과:** 토큰 사용량 ~50-70% 절감

## 5.6 인증 시스템

### NextAuth.js + Credentials Provider

```
┌─────────────────────────────────────────┐
│              로그인 플로우               │
├─────────────────────────────────────────┤
│  1. 사용자 ID/PW 입력                   │
│  2. bcrypt 해시 검증                    │
│  3. JWT 토큰 발급 (role 포함)           │
│  4. 세션에 user.id, user.role 저장     │
│  5. Admin 페이지 접근 시 role 체크      │
└─────────────────────────────────────────┘
```

### 보안 고려사항
- 비밀번호 bcrypt 해싱
- CSRF 보호
- 세션 기반 인증
