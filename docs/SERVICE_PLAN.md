# BTS (Build Team Service) - 가상 AI 팀 협업 서비스

## 1. 서비스 개요

### 1.1 비전
> "목표만 있으면, 팀은 우리가 만들어 드립니다"

사용자가 달성하고 싶은 목표를 입력하면, 해당 목표에 최적화된 가상 AI 팀원들이 구성되어 협업을 통해 결과물을 만들어주는 서비스

### 1.2 핵심 가치
- **맞춤형 팀 구성**: 목표에 따라 필요한 역할과 팀원 자동 추천
- **다양한 관점 제공**: 주니어(혁신) + 시니어(검증) 협업 구조
- **실시간 협업 시각화**: AI 팀원들의 논의 과정을 투명하게 공개
- **반복 개선**: 피드백을 통한 결과물 고도화

## 2. 핵심 개념

### 2.1 역할(Role) 시스템

| 역할 | 주요 책임 | 활용 시나리오 |
|------|----------|--------------|
| 기획자 (Planner) | 전략 수립, 요구사항 정의, 일정 관리 | 기획서, 제안서, 로드맵 |
| 디자이너 (Designer) | UI/UX 설계, 시각적 방향 제시 | 와이어프레임, 디자인 가이드 |
| 개발자 (Developer) | 기술 검토, 구현 가능성 분석 | 기술 스펙, 아키텍처 설계 |
| QA 엔지니어 (QA) | 품질 검증, 예외 케이스 발견 | 테스트 케이스, 리스크 분석 |
| 마케터 (Marketer) | 시장 분석, 포지셔닝 전략 | 마케팅 전략, 경쟁 분석 |
| 데이터 분석가 (Analyst) | 데이터 기반 의사결정 지원 | 지표 설계, 분석 리포트 |

```
     │                           │
     └───────────┬───────────────┘
                 ↓
          [통합된 결과물]
```

## 3. 사용자 플로우

### 3.1 기본 플로우

```
1. 목표 입력
   └─→ "새로운 기획서를 작성하고 싶어요"

2. 팀 구성 추천
   └─→ AI가 목표 분석 후 필요한 역할/팀원 추천
       • 추천: 기획자(2), 디자이너(1), QA(1)

3. 팀 커스터마이징 (선택)
   └─→ 사용자가 역할/인원 조정 가능

4. 협업 시작
   └─→ AI 팀원들이 순차적으로 의견 제시
       • 실시간 대화 형태로 진행 과정 시각화

5. 결과물 생성
   └─→ 논의 결과를 바탕으로 최종 산출물 생성

6. 피드백 & 반복
   └─→ 사용자 피드백 반영하여 결과물 개선
```

## 4. 주요 기능

### 4.1 목표 기반 팀 자동 구성

```yaml
입력: "모바일 앱 기획서를 작성하고 싶어요"

분석 결과:
  - 키워드: [모바일, 앱, 기획서]
  - 카테고리: 제품 기획
  - 추천 팀:
      기획자: 2명 (Jr 1, Sr 1)
      디자이너: 2명 (Jr 1, Sr 1)
      개발자: 1명 (Sr 1)
      QA: 1명 (Sr 1)
```

### 4.2 팀원 페르소나

각 팀원은 고유한 성격과 관점을 가짐:

| 이름 | 역할 | 레벨 | 특성 |
|------|------|------|------|
| 민준 | 기획자 | Jr | 트렌드에 민감, MZ세대 관점, 과감한 제안 |
| 서연 | 기획자 | Sr | 데이터 기반 사고, 리스크 관리, 균형 잡힌 시각 |
| 지호 | 디자이너 | Jr | 실험적 디자인, 최신 UI 트렌드 적용 |
| 수아 | 디자이너 | Sr | 사용성 중심, 브랜드 일관성, 접근성 고려 |
| 현우 | QA | Sr | 꼼꼼한 검토, 엣지 케이스 발견, 품질 기준 수립 |

### 4.3 협업 모드

| 모드 | 설명 | 용도 |
|------|------|------|
| 브레인스토밍 | 자유로운 아이디어 발산 | 초기 기획, 아이디어 수집 |
| 토론 | 찬반 의견 교환 | 의사결정, 방향 설정 |
| 리뷰 | 결과물 검토 및 개선 | 품질 향상, 완성도 높이기 |
| 실행 | 각자 역할에 맞는 산출물 작성 | 최종 결과물 생성 |

### 4.4 결과물 유형

- 📋 **기획서**: 서비스/제품 기획 문서
- 📊 **제안서**: 프로젝트 제안 및 견적
- 🎨 **디자인 가이드**: UI/UX 방향성 문서
- 🔧 **기술 스펙**: 아키텍처 및 기술 명세
- 📈 **분석 리포트**: 시장/데이터 분석 보고서
- ✅ **테스트 계획**: QA 전략 및 테스트 케이스
